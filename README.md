These files are meant to accompany the paper titled ‘Primitive representations by positive ternary quadratic forms: A combinatorial approach’ by Z.S. Aygin, F. Munkel and K.S. Williams. 

Instructions to work with the functions defined in the paper:
1) Start a Jupyter notebook with SageMath kernel.
2) Put the file named ‘CombinatorialTernaryFunctions.ipynb’ in the same folder as the working Jupyter notebook file.
3) Execute the code %run CombinatorialTernaryFunctions.ipynb.

Then all the functions defined in the paper can be used in the Jupyter notebook. The codes were written and tested with SageMath version 10.4. For those who do not have SageMath installed, CoCalc is the easiest way to get started.
